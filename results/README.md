# Results directory

Running `main.m` writes the reproducibility outputs to this directory:

- `figure5_results.mat`: complete Monte Carlo output (`myoutput`), the settings
  used for the run, and aggregate MSE/R-squared summaries.
- `run_summary.txt`: a small human-readable record of the dimensions,
  rank, missing rate, noise variance, MSE, and R-squared.
- Seven `.fig` files and seven 300-dpi `.png` files: the network goodness-of-fit
  and residual-diagnostic panels generated by `main.m`.

Generated result files are ignored by Git so that the repository stays small.
